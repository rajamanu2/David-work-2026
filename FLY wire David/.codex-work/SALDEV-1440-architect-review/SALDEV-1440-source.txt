P23 [normal]: User Story:
P24 [normal]: As a sales user, I need to be able to use Quote Line Groups for both Stepped Up Pricing and for other purposes, such as separating quote lines by Ship to Account or Payments. I must be able to toggle between these use cases to allow for different UI and business rules behavior.

P26 [normal]: As a system, there must be backend logic to indicate when quote line groups are being used for stepped up pricing vs for another use, such as separating lines by ship to account.
P28 [normal]: This indicator must be visible in quote to user and will be used in other system logic to apply stepped up pricing guardrails only when appropriate
